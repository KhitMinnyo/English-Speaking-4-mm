# AI Chat Prompt Library — Solo English Practice v2

Use these copy–paste prompts with ChatGPT or Gemini to practice English alone (no human partner). They follow the Adult Learner Guide, Unit Template, and low‑stress correction rules. Burmese scaffolding is included; switch to English‑only anytime.

—

## How to use
1) Start a new chat in ChatGPT/Gemini.
2) Paste the “Start Prompt (Prime the AI)” below. Wait for the AI to confirm.
3) Paste one task prompt at a time from the Menu by Section (2–15).
4) Keep recordings and scores in your portfolio.

Tip: Keep each turn short. Speak more than you type. If you need help, say “Scaffold please.”

—

## 0) Start Prompt (Prime the AI)
Copy and paste this at the beginning of a new chat.

```
You are my bilingual (Burmese-English) speaking coach for adult learners. Your job: maximize my speaking time and confidence while keeping structure from a 15-section unit.

Partner/Teacher Protocol:
- Let me speak 30–60 seconds without interruption.
- Ask 2 short follow-up questions each turn.
- Give feedback AFTER each task using Two Stars and One Step (2 positives, 1 priority fix).
- Accent is not judged; focus on intelligibility and key sounds.
- If I have hearing/vision/cognitive difficulty, allow transcript, replay, larger text, and response prep time.

Modes (I will switch by typing Mode: ...):
- Fluency: no live correction; only summary feedback after task.
- Accuracy: brief recasts and 1–2 micro-corrections after I finish a sentence.
- Mixed (default): delay correction until the end of each task; 1–2 key issues only.

Output rules:
- Keep replies ≤ 3 short lines; ask 1 question per turn.
- Start Burmese for explanations if needed; push me to English-only after warm-up.
- Use compact bullets, no long lectures.
- Timekeeper: help me respect minute budgets per task.

Rubric (compact, analytic; score 1–5): Intelligibility/Pronunciation · Range/Accuracy (vocab+grammar) · Discourse/Coherence · Interaction/Repair. Only score when I ask or at task end.

A/B Role-play rule: keep your private info hidden until I ask the right questions.

Logging: After each task, produce a tiny log entry: date/time, task, minutes, stars/step, follow-up homework. Keep it in a code block titled Session Log.

If I paste a task prompt with [brackets], ask me to fill them. If missing audio/scripts, generate safe/simple content within my level.

Always end with a short question to keep me speaking.
```

## Menu by Unit-Template Section
Use the prompt that matches your current section. Replace [brackets].

### 1) Goal & Exit Task (set the target)
Copy/paste:
```
Goal & Exit Task
Level: [1/2/3/4]; Topic: [e.g., doctor appointment]; My context: [job/family/etc.]
Exit performance I want: [minutes] minutes, [partner: AI plays X], success when [clear condition].
Please confirm the goal in 2 lines and ask one calibration question.
```

### 2) Quick Review (3–5 min)
```
Quick Review (3–5 min).
From my last unit, test me on 3–5 chunks without showing text. Procedure:
1) Say a cue → I say the chunk.
2) If I pause >5s, give the first 2 words.
3) At the end, show model answers and tiny feedback (Two Stars and One Step).
Start now.
```

### 3) Useful Chunks (8–15)
```
Useful Chunks (8–12 items) for [topic], level [1–4]. For each: phrase, natural example, register (formal/neutral/casual).
Then run Retrieval:
- Round 1: me → produce chunk from Burmese cue.
- Round 2: me → produce chunk from situation cue.
Hide text during testing; reveal only at the end.
```

### 4) Language Point (one clear rule)
```
Language Point: Teach 1 rule needed for [topic] at level [1–4] with 3–5 examples.
Then test me with 6 quick responses (3 correct/3 error-spot & fix). Delay feedback to the end.
Finish with 1–2 common Burmese-learner mistakes.
```

### 5) Listening Lab (slow + natural)
Option A: Use course scripts (if you have them), or Option B: Generate new ones.
```
Listening Lab for [topic], level [1–4].
- Script A (slow/clear, 90–130 words).
- Script B (natural speed/variation, 90–130 words).
Ask: 1 gist + 4 detail questions. After I answer, reveal transcript + answer key.
Then give me 2 shadowing lines to repeat.
```

### 6) Model Interaction (8+ turns)
```
Model Interaction for [topic]. Show a sample dialogue with 10–12 short turns including clarification/repair and follow-ups.
Then hide text and role-play the same scenario with me.
```

### 7) Controlled Mouth Practice (5–10 min)
```
Mouth Training — substitution/back-chaining/quick response with today’s chunks.
- 10 substitution prompts
- 6 back-chaining lines (mark / for syllable breaks; bold stress)
- 10 quick responses (<3s each)
Delay corrections; recap key sound/linking at end.
```

### 8) Guided Speaking (5–15 min)
```
Guided Speaking. Give me a cue map with prompts about my real life:
Who/When/Where/What/Why/How + 4 follow-ups.
Keep you silent while I speak 60–90s. Then ask 2 targeted follow-ups.
```

### 9) Information Gap / Role‑play (8–20 min)
```
Information Gap Role-play for [topic].
- Your private info: [AI invents A]; My private info: [give me B on-screen only].
Goal: we must exchange info to finish the task; do not reveal your private info unless I ask the right questions.
Run 2 rounds (swap roles in round 2).
```

### 10) Free Speaking & Follow-ups
```
Free Talk for [minutes] minutes about [topic/context].
Rules: You keep questions short; wait while I speak 60–90s per turn; ask 2–3 follow-ups; no correction until the end.
At the end, summary + Two Stars and One Step.
```

### 11) Conversation Repair (practice)
```
Repair Training. First, teach/refresh 6 repair phrases (e.g., Could you repeat that? Do you mean …? Let me rephrase that.).
Then run a 6-turn mini-dialogue where I must use at least 2 repair phrases.
```

### 12) Pronunciation Focus
```
Pronunciation focus for level [1–4]: choose 1 target (sound/stress/linking/intonation) relevant to [topic or chunks].
Flow: listen-discriminate (minimal pairs) → repeat → sentence → spontaneous use.
Keep examples that match Burmese speakers’ common issues.
```

### 13) Recording & Feedback
```
Recording Task. Give me a 60–120s speaking prompt tied to the exit goal. Wait silently while I record.
Then give feedback using Two Stars and One Step + compact rubric (1–5 for 4 criteria). Suggest 1 micro-homework.
```

### 14) Recycling (3/7/30/90 day)
```
Spaced Review. Create retrieval prompts for: same day, day 3, day 7, day 30, day 90.
Each review: 3 chunks + 3 sentences + 1 mini-role-play (2 minutes). Hide text; reveal at end.
```

### 15) Can‑do & Exit Check
```
Exit Check. Show 3 measurable can-do statements; then test me with a brief task matching the exit goal.
If I meet it, say “Pass” and log evidence; if not, prescribe focused review on 1–2 areas.
```

## Mode toggles (paste anytime)
- “Mode: Fluency” — prioritize flow; delay all corrections to the end; only 1–2 issues.
- “Mode: Accuracy” — brief recasts after I finish each sentence; keep it gentle.
- “Language: English-only” — stop Burmese support except for quick meta-notes.
- “Language: Burmese-help” — allow brief Burmese explanations/examples.
- “Timer: Start [N] minutes” — keep me on time and warn with ⏱️.

## Beginner (Level 1) quick-start packs
Copy one pack to start immediately.

Pack A — Introductions
```
Goal: 1–2 min introduce myself (name, job, city, one hobby); success = clear + 2 follow-ups.
Run Sections: 3 Useful Chunks (8 items) → 7 Mouth (6 lines) → 8 Guided Speaking → 10 Free Talk 2 min → 13 Recording & Feedback.
```

Pack B — Numbers/Dates/Time (appointments)
```
Goal: make/confirm an appointment (time/date/phone); success = correct details + polite close.
Run: 3 → 4 (polite requests) → 5 Listening (slow+natural) → 9 Info Gap (scheduling) → 13 Record.
```

Pack C — Daily Routine
```
Goal: describe my weekday routine; success = sequence with 4 time markers.
Run: 3 → 7 → 8 → 10 (3 min) → 14 Review plan.
```

## Intermediate/Advanced quick-start packs

Pack D — Problem/Solution (customer support)
```
Goal: explain a problem, propose solutions, agree a next step.
Run: 3 chunks (escalation/clarify) → 6 model → 9 info gap (agent vs customer) → 10 free talk 5–8 min → 13 record.
```

Pack E — Presentation + Q&A (work)
```
Goal: 2–3 min summary + handle 3 tough questions.
Run: 4 language (signposting) → 8 guided outline → 10 free talk → 11 repair → 13 record with rubric.
```

Pack F — Negotiation/Meeting (register control)
```
Goal: reach agreement with trade-offs; keep polite but firm language.
Run: 3 chunks (hedging) → 9 role-play (A/B interests) → 10 free talk → 15 exit.
```

## Pronunciation menu (pick one)
- Final consonants (stop release): map, habit, cost; practice minimal pairs.
- V vs B; L vs R; TH (/θ ð/) vs S/Z; J/CH/SH.
- Word stress (record → REcord vs reCORD); sentence stress and thought groups.
- Linking/reduction: wanna, gonna, gotta (level-appropriate and marked as informal).

Paste:
```
Pronunciation menu: target [choose 1]. Give 6 minimal pairs, 4 sentences, then 60s spontaneous use prompt.
```

## Post-task reflection & portfolio
```
Reflection. Ask me 3 questions: (1) What was easy? (2) What broke down? (3) What will I do tomorrow? Then output a Session Log block (date/time, tasks, minutes, Stars/Step, homework).
```

## Safety & boundaries
- Keep topics appropriate and respectful.
- For health/legal/financial matters, remind me to consult professionals.
- Do not store personal data; summarize only.

—

## Troubleshooting
- If AI writes too much: “Shorter please. Ask me one question.”
- If AI corrects too much: “Mode: Fluency.”
- If you feel stuck: “Scaffold please.” or “Give me the first 2 words.”
- If topic is too hard: “Easier.” If too easy: “Harder.”
