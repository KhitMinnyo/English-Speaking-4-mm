# English Speaking Mastery — AI-First Solo Course (Level 1–4, v2)

## ရည်ရွယ်ချက်

ဒီ course က English စာကို သိရုံမဟုတ်ဘဲ **နားထောင်ပြီး အကြောင်းအရာမျိုးစုံကို တကယ်ကြာကြာ ပြောနိုင်ရန်** ရည်ရွယ်သည်။ **v2 မှာ အဓိကပြောင်းလဲချက်က** — ပြောဖော်လူတစ်ယောက်၊ ဆရာတစ်ယောက် ရှိမှသာ လေ့ကျင့်လို့ရတဲ့ပုံစံကို ဖျက်ပြီး၊ **ChatGPT/Gemini စတဲ့ AI chat (live/voice mode) ကို “စကားပြောဖော် + နောက်ခံဆရာ” အဖြစ် အသုံးပြု၍ တစ်ယောက်တည်း နေ့တိုင်း လေ့ကျင့်နိုင်တဲ့ပုံစံ** ဖြစ်လာသည်။

သင်ယူနှုန်းနှေးလာနိုင်သော လူကြီးများအတွက် Burmese scaffolding, အဆင့်သေးသေး၊ ထပ်ခါတလဲလဲလေ့ကျင့်မှု၊ audio/shadowing၊ retrieval practice နဲ့ အရှက်မရှိဘဲ ပြန်စနိုင်သော review path ကို မပြောင်းဘဲ ထားရှိသည်။

> **CEFR မှတ်ချက်:** Unit ပြီးရုံနဲ့ CEFR level အလိုအလျောက်မရပါ။ Level label များသည် target direction ဖြစ်ပြီး placement/progress/final performance test နဲ့သာ အတည်ပြုရမည်။ ပန်းတိုင်က accent တစ်မျိုးတည်းကို တုပခြင်းမဟုတ်ဘဲ clear, intelligible, flexible communication ဖြစ်သည်။

## v2 — AI-First ဘာတွေပြောင်းလဲသွားလဲ

| အရင် (v1) | အခု (v2 — AI-first) |
|---|---|
| Partner/teacher ၂–၃ ယောက်လိုအပ် | လူအဖော်မလိုဘဲ AI chat (ChatGPT/Gemini live/voice) နဲ့ တစ်ယောက်တည်း |
| Information-gap role-play ကို လူနှစ်ယောက်နဲ့ | AI က private info ကိုင်ထားပြီး ၁ ယောက်တည်း A/B role-play |
| ဆရာက အချိန်မှတ်ပေးရ | AI က timekeeper + follow-up မေးပေး၊ သင်က pace ထိန်း |
| Feedback ရဖို့ စောင့်ရ | Task အပြီး ချက်ချင်း Two Stars and One Step |
| Correction ကို လူကထိန်း | Mode: Fluency/Accuracy/Mixed ဖြင့် ကိုယ်တိုင်ထိန်း |

AI ရဲ့ အားသာချက်: partner မလို၊ အချိန်ကိုယ်ထိန်း၊ ထပ်ခါတလဲလဲ ပြောခိုင်းလို့ရ၊ level ကိုချက်ချင်း ချိန်၊ 24/7 ရနိုင်၊ ဝေဖန်ခံရမှာမကြောက်ရ။

## ဘယ်သူတွေအတွက်လဲ

- Beginner မှ advanced adult learners (အရွယ်ကန့်သတ်မရှိ)
- **ပြောဖော်လူ ရှာမရသူ၊ တစ်ယောက်တည်း လေ့ကျင့်ချင်သူ**
- အချိန်နည်းသူ၊ မှတ်ဉာဏ်ပြန်ခေါ်ရန် အကြိမ်များစွာလိုသူ
- ခရီးသွား၊ နေ့စဉ်ဘဝ၊ အလုပ်၊ ပညာရေးနဲ့ လူမှုဆက်ဆံရေးမှာ English ပြောလိုသူ
- Reading/grammar သိပေမဲ့ ပါးစပ်က မထွက်သေးသူ

## Level နှင့် လက်တွေ့ Outcome

| Level | Target | Teaching + review | Exit performance (အနည်းဆုံး) |
|---|---|---:|---|
| 1 Foundation | A1 → A2-oriented | 16 weeks | AI အကူအညီနဲ့ နေ့စဉ်အကြောင်း 3–5 မိနစ်၊ routine transaction လုပ်နိုင် |
| 2 Independent | A2 → B1/B2-oriented | 16 weeks | familiar topic conversation 8–12 မိနစ်၊ story/opinion/problem solution ပြောနိုင် |
| 3 Proficient | B2 → C1-oriented | 16 weeks | complex discussion 15–20 မိနစ်၊ presentation/Q&A/negotiation ကို register သင့်တော်စွာလုပ်နိုင် |
| 4 Mastery | C1 → C2-oriented | 16+ weeks | unfamiliar/abstract topic ကို nuance, synthesis, mediation ပါစွာ 20–30 မိနစ် ဆွေးနွေးနိုင် |

**စုစုပေါင်း:** core 64 weeks (3 teaching units + 1 review/assessment week per 4-week block)။ တစ်ရက် 15–30 မိနစ်သင်သူအတွက် 18–30 လကြာနိုင်သည်။ Level 4 ပြီးဆုံးခြင်းသည် C2 certificate မဟုတ်ဘဲ C2-oriented training ဖြစ်ပြီး independent assessment လိုအပ်သည်။

## “စကားများများပြောနိုင်ရန်” Output Standard (AI နဲ့)

Unit တိုင်းမှာ learner က အနည်းဆုံး—

1. Model audio/script ကို slow နဲ့ natural speed နှစ်မျိုးနားထောင်ခြင်း (repository script သို့မဟုတ် AI generated)
2. Chunk 8–15 ခုကို အသံထွက် retrieval လုပ်ခြင်း
3. Controlled drill 5–10 မိနစ် (AI က prompt ပေး)
4. Guided speaking 5–15 မိနစ် (AI က cue + follow-up ပေး)
5. Information-gap/role-play interaction 8–20 မိနစ် (AI က hidden info ကိုင်)
6. Free talk/real-life task 3–10 မိနစ် (AI က open question ပေး)
7. Recording တစ်ခုနဲ့ AI/rubric feedback တစ်ခုပြုလုပ်ခြင်း
8. 3-day, 7-day, 30-day recycling လုပ်ခြင်း (AI က retrieval prompt ဆွဲ)

Level မြင့်လာသလို weekly speaking target ကို 60 → 90 → 120 → 150+ မိနစ် တိုးမည်။

## သင်ကြားနည်း (AI-first)

- **AI as partner + coach:** ChatGPT/Gemini live/voice mode ကို ပြောဖော်လိုက်၊ ဆရာလိုက် အသုံးပြု
- **Copy-paste prompts:** `AI-Chat-Prompt-Library.md` ထဲက Start Prompt ကို paste → section prompt တစ်ခုစီ paste
- **Adult-friendly microlearning:** တစ်ကြိမ် 10–25 မိနစ်၊ instruction တစ်ခုစီတို
- **Comprehensible input:** Burmese support → bilingual cue → English-only performance
- **Chunks before rules:** reusable phrase ကို အရင်ပြော၊ grammar ကို နောက်မှရှင်း
- **I do → We do → You do:** AI model → guided rehearsal → independent output
- **Retrieval + spaced repetition:** ကြည့်ဖတ်ခြင်းထက် မကြည့်ဘဲ ပြန်ပြောခြင်း
- **Communicative/task-based learning:** information gap, repair, follow-up, real outcome (AI က hidden info ကိုင်)
- **Low-stress correction:** ပြောနေစဉ် မဖြတ်ဘဲ task အပြီး 1–2 target errors သာပြင် (Mode ဖြင့်ထိန်း)
- **AI as timekeeper:** minute budget ကို AI က ကြည့်၊ ကိုယ်က pace ချိန်
- **Portfolio evidence:** dated recordings, rubric scores, reflection နဲ့ တိုးတက်မှုကိုပြ

## စတင်ရန် (5 မိနစ်အတွင်း ပြောစ)

1. `Assessments/Placement-Test.md` ဖြေပြီး သင့်တော်သော starting point ရွေးပါ။
2. ChatGPT သို့မဟုတ် Gemini ဖွင့် → `AI-Chat-Prompt-Library.md` ထဲက **Start Prompt (Prime the AI)** ကို paste ပါ။
3. `Adult-Learner-Guide.md` ထဲက Easy/Standard/Intensive pace တစ်ခုရွေးပါ။
4. Unit တစ်ခုစီကို listening → rehearsal → interaction → recording အစဉ်နဲ့ AI နဲ့တွဲလုပ်ပါ။
5. Score 70% အောက် သို့မဟုတ် rubric criterion တစ်ခု 2 အောက်ဖြစ်ရင် review week လုပ်ပြီး ပြန်စမ်းပါ။
6. Level တစ်ခုကို final performance evidence ရှိမှသာပြီးဆုံးသည်ဟု မှတ်ပါ။
