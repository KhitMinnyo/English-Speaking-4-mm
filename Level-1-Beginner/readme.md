# Level 1 — Foundation (A1 → A2-oriented)

## Course Overview

လူကြီး learner များအတွက် နေ့စဉ်ဘဝအခြေခံ ကို စကားများများပြောရင်း တည်ဆောက်ပေးသော 16-week flexible block ဖြစ်သည်။ Teaching Unit ၁၂ ခုနှင့် review/assessment week ၄ ခုသုံးပါ။ တစ်ကြိမ် 10–25 မိနစ်စီ ခွဲသင်နိုင်သည်။

> **CEFR မှတ်ချက်:** ဒီ Level ပြီးရုံဖြင့် CEFR certificate မရပါ။ Target direction သာဖြစ်ပြီး placement/progress/final performance evidence နှင့် independent assessment ဖြင့်သာ အတည်ပြုရမည်။

## Speaking-First Standard

- Unit တစ်ခုလျှင် စုစုပေါင်း oral practice **25–45 မိနစ်**
- Notes မကြည့်သော free talk/recording **2–3 မိနစ်**
- Listening lab: Unit အတွင်းရှိ link မှ `Audio-Scripts/` script ကိုသုံးပါ။
- Retrieval → controlled mouth practice → guided talk → information gap → free talk → recording အစဉ်လိုက်လုပ်ပါ။
- Conversation-repair phrases၊ listener follow-ups နဲ့ role switching မဖြစ်မနေပါဝင်ရမည်။
- Day 3, Day 7, Day 30 တွင် retrieval/re-recording လုပ်ပါ။

## Exit Performance

အနည်းဆုံး **3–5 မိနစ် supported conversation** ကို task outcome ရှိစွာလုပ်နိုင်ရမည်။ `../Assessments/Speaking-Rubric.md` ဖြင့် score ပေးပြီး final test evidence၊ dated recording နှင့် reflection သိမ်းပါ။ Criterion တစ်ခု 2 အောက်ဖြစ်လျှင် review/retry; Level 4 တွင် criterion တစ်ခုမှ 3 အောက်မရှိရ။

## Adult-Friendly Use

- ပင်ပန်းလျှင် Easy Pace သုံးပြီး task ကို session ၂–၄ ခုခွဲပါ။
- Burmese cue ကို ပထမ round သာသုံး၊ နောက် round တွင် cue words၊ နောက်ဆုံး English-only လုပ်ပါ။
- စကားပြောနေချိန် အမှားအားလုံးမဖြတ်ပြင်ဘဲ task အပြီး အရေးကြီးဆုံး 1–2 ခုသာပြင်ပါ။
- Pair မရှိလျှင် A/B role နှစ်ခုစလုံးကို အသံပြောင်း record လုပ်ပါ။
