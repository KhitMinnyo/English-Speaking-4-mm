# Unit 07: Shopping & Prices (စျေးဝယ်ခြင်းနှင့် ဈေးနှုန်း)

## Goal

ဒီ unit ပြီးရင် ဈေးဝယ်ရင်း ဈေးနှုန်းအကြောင်း English လို ပြောနိုင်ပါလိမ့်မယ်။

## 1. Vocabulary Warm-up

| English | Burmese | Example |
|---|---|---|
| shirt / shoes | ရှပ်အင်္ကျီ / ဖိနပ် | I like this shirt. |
| size | အရွယ်အစား | Do you have a bigger size? |
| color | အရောင် | What color do you want? |
| price | ဈေးနှုန်း | What's the price of this bag? |
| expensive / cheap | ဈေးကြီး / ဈေးသက်သာ | This is too expensive. |
| discount | ဈေးလျှော့ | Is there a discount? |
| How much is this? | ဒါဘယ်လောက်လဲ | How much is this shirt? |

## 2. Grammar Point: this/that/these/those & Comparatives

this (near, singular) / these (near, plural) — that (far, singular) / those (far, plural)
Comparative: bigger, cheaper, more expensive (adj+er / more+adj)

Examples:
- How much is this shirt? / How much are these shoes?
- That bag is cheaper than this one.
- This shirt is more expensive than that one.

## 3. Model Dialogue

Customer: Excuse me, how much is this shirt?
Seller: It's 15,000 kyats.
Customer: Do you have a bigger size?
Seller: Yes, here you are. This one is a large.
Customer: Great. Is there a discount?
Seller: Yes, today it's 10% off.
Customer: That's good! I'll take this one. Do you have it in blue?
Seller: Yes, blue is more popular than red.
Customer: Perfect, I'll take the blue one.

## 4. Practice Exercise

Choose this/that/these/those and complete comparatives:

1. ___ shoes (near you) are nice.
2. ___ bag (far away) is expensive.
3. A bicycle is ___ (cheap) than a car.
4. This phone is ___ (expensive) than that one.
5. How much ___ this shirt?

Answer key: 1. These 2. That 3. cheaper 4. more expensive 5. is

## 5. Speaking Drill

Partner နဲ့ shop customer/seller role-play — sizes, colors, price negotiate လုပ်ကြည့်ပါ။

## 6. Pronunciation Focus

/ð/ sound in this/that/these/those — လျှာဖျားကို သွားနှစ်ခြမ်းကြားထားပြီး အသံထွက်ပါ။

## 7. Can-do Checklist

- [ ] I can ask about prices and sizes
- [ ] I can use this/that/these/those correctly
- [ ] I can compare two items using comparatives

## Speaking-First Extension (မဖြစ်မနေ လုပ်ရန်)

> **Topic:** Unit 07: Shopping & Prices (စျေးဝယ်ခြင်းနှင့် ဈေးနှုန်း)  
> **စုစုပေါင်း ပါးစပ်ဖြင့်ပြောချိန်:** 25–45 မိနစ် (တစ်ခါတည်းမလို—အပိုင်းခွဲနိုင်သည်)

### A. Quick Retrieval (3–5 min)

စာအုပ်ကိုပိတ်ပြီး ဒီ unit မှ အသုံးဝင်သော phrase ၅ ခုကို အသံထွက်ပြောပါ။ Phrase တစ်ခုစီနဲ့ ကိုယ့်ဘဝအကြောင်း sentence အသစ်တစ်ကြောင်း ဆောက်ပါ။ မမှတ်မိလျှင် ကြည့်ပြီး ပြန်ပိတ်ကာ ထပ်ပြောပါ။

### B. Listening Lab

[`Unit-07-Shopping-and-Prices Listening Lab`](../Audio-Scripts/Level-1-Beginner/Unit-07-Shopping-and-Prices-Listening.md) ကို အသုံးပြုပါ။

1. **မနားထောင်မီ:** ဘယ်သူတွေ၊ ဘယ်နေရာ၊ ဘာပြဿနာဖြစ်နိုင်သလဲ ခန့်မှန်းပါ။
2. **Slow version:** အဓိကအကြောင်းကို sentence တစ်ကြောင်းနဲ့ ပြောပါ။
3. **Natural version:** ကြားရသော detail ၃ ခုရေး/ပြောပါ။
4. Transcript ကြည့်ပြီး shadow ၃ ကြိမ်လုပ်ပါ—listen → pause → copy; နောက်ဆုံးတစ်ကြိမ် transcript မကြည့်ရ။

### C. Controlled Mouth Practice (5 min)

Model Dialogue မှ sentence pattern ၅ ခုရွေးပါ။ လူ၊ နေရာ၊ အချိန် သို့မဟုတ် အမြင်ကို အစားထိုးပြီး pattern တစ်ခုလျှင် sentence ၃ ကြောင်း ခပ်မြန်မြန်ပြောပါ။ မှားလျှင် စာကြောင်းအစမှ အေးအေးဆေးဆေး ပြန်ပြောပါ။

### D. Guided Personal Talk

ဒီ unit topic ကို ကိုယ့်အတွေ့အကြုံနဲ့ချိတ်ပြီး **အချက် ၅ ချက်** ပြောပါ။ `First...`, `One example is...`, `The reason is...`, `Another thing is...`, `So...` frame များသုံးနိုင်သည်။ Partner က `Why?`, `Can you give an example?`, `What happened next?` တို့ထဲက follow-up အနည်းဆုံး ၃ ခုမေးရမည်။

### E. Information Gap / Role-play (8 min)

- **Student A:** ကိုယ့်အတွက် လိုအပ်သော detail ၅ ခုကို လျှို့ဝှက်ရွေးပြီး မပြပါနှင့်။
- **Student B:** မတူသော detail ၅ ခုရွေးပါ။
- Topic နဲ့ဆိုင်တဲ့ plan/decision တစ်ခုကို နှစ်ဦးသဘောတူအောင် မေးခွန်းမေး၊ option နှိုင်းယှဉ်၊ နားလည်မှုစစ်ပါ။ Detail အားလုံးကို ရှာမတွေ့မချင်း task မပြီးပါ။ Role ပြောင်းပြီး ထပ်လုပ်ပါ။

### F. Conversation Repair

- `Sorry, could you say that again?`
- `Do you mean ...?`

Phrase နှစ်ခုကို role-play ထဲမှာ တစ်ကြိမ်စီ မဖြစ်မနေသုံးပါ။

### G. Free Talk & Recording

Notes မကြည့်ဘဲ topic အကြောင်း **2–3 မိနစ်** ပြောပြီး ဖုန်းနဲ့ record လုပ်ပါ။ [Speaking Rubric](../Assessments/Speaking-Rubric.md) ထဲက **Fluency, Task Achievement, Interaction** ကို score ပေးပါ။ ကောင်းတာ ၂ ခုနဲ့ ပြင်မည့်အချက် ၁ ခုရေးပြီး ပြန် record လုပ်ပါ။

### H. Recycling

- **3 days:** phrase ၅ ခု + ၁ မိနစ် talk ကို memory မှလုပ်ပါ။
- **7 days:** role-play ကို role အသစ်နဲ့ ပြန်လုပ်ပါ။
- **30 days:** recording ပြန်လုပ်ပြီး rubric score နှိုင်းပါ။
