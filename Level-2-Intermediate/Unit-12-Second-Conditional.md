# Unit 12: Second Conditional & Hypothetical Talk

## Goal

ဒီ unit ပြီးရင် ဖြစ်နိုင်ခြေနည်း/မဖြစ်နိုင်တဲ့ အခြေအနေတွေကို hypothetical အနေနဲ့ ပြောနိုင်ပါလိမ့်မယ် — Level 2 ရဲ့ နောက်ဆုံး unit ဖြစ်ပါတယ်။

## 1. Vocabulary Warm-up

| English | Burmese | Example |
|---|---|---|
| If I were you... | မင်း နေရာမှာ ကျွန်တော်ဆိုရင်... | If I were you, I would rest more. |
| I would... | ကျွန်တော်ဆိုရင် ...လုပ်မယ် | I would travel the world if I had money. |
| wish | ဆန္ဒရှိသည် | I wish I could speak French. |
| imagine | စိတ်ကူးကြည့်သည် | Imagine if you won the lottery. |

## 2. Grammar Point: Second Conditional (If + past simple, would + verb)

Used for hypothetical/imaginary/unlikely situations (present or future). If + Past Simple, ... would + base verb.

Examples:
- If I had more time, I would learn another language.
- If I were you, I would apologize.
- What would you do if you won the lottery?

## 3. Model Dialogue

A: If you won the lottery, what would you do?
B: I would travel around the world! What about you?
A: I would buy a house for my parents.
B: That's so kind! If I were you, I would also save some money.
A: Good idea. What would you do if you had more free time?
B: I would learn to play the guitar. I've always wanted to.
A: If I were you, I would start now — don't wait for "more time"!
B: You're right. I should just start today.

## 4. Practice Exercise

Complete with Second Conditional:

1. If I ___ more money, I ___ more. (have / travel)
2. If I ___ you, I ___ to her. (be / apologize)
3. What ___ you ___ if you ___ your job? (do / lose)
4. If she ___ the answer, she ___ us. (know / tell)
5. I ___ English faster if I ___ every day. (learn / practice)

Answer key: 1. had, would travel 2. were, would apologize 3. would, do, lost 4. knew, would tell 5. would learn, practiced

## 5. Speaking Drill

Partner ကို hypothetical question ၃ ခု မေးပါ — "What would you do if...?" (win the lottery / could travel anywhere / could meet anyone)။

## 6. Pronunciation Focus

"would" ကို connected speech မှာ "I'd", "you'd", "she'd" (weak /əd/) အဖြစ် ချုံ့ပြောလေ့ရှိပါတယ်။

## 7. Can-do Checklist

- [ ] I can talk about hypothetical situations using Second Conditional
- [ ] I can give advice using "If I were you..."

## Speaking-First Extension (မဖြစ်မနေ လုပ်ရန်)

> **Topic:** Unit 12: Second Conditional & Hypothetical Talk  
> **စုစုပေါင်း ပါးစပ်ဖြင့်ပြောချိန်:** 45–75 မိနစ် (တစ်ခါတည်းမလို—အပိုင်းခွဲနိုင်သည်)

### A. Quick Retrieval (3–5 min)

စာအုပ်ကိုပိတ်ပြီး ဒီ unit မှ အသုံးဝင်သော phrase ၅ ခုကို အသံထွက်ပြောပါ။ Phrase တစ်ခုစီနဲ့ ကိုယ့်ဘဝအကြောင်း sentence အသစ်တစ်ကြောင်း ဆောက်ပါ။ မမှတ်မိလျှင် ကြည့်ပြီး ပြန်ပိတ်ကာ ထပ်ပြောပါ။

### B. Listening Lab

[`Unit-12-Second-Conditional Listening Lab`](../Audio-Scripts/Level-2-Intermediate/Unit-12-Second-Conditional-Listening.md) ကို အသုံးပြုပါ။

1. **မနားထောင်မီ:** ဘယ်သူတွေ၊ ဘယ်နေရာ၊ ဘာပြဿနာဖြစ်နိုင်သလဲ ခန့်မှန်းပါ။
2. **Slow version:** အဓိကအကြောင်းကို sentence တစ်ကြောင်းနဲ့ ပြောပါ။
3. **Natural version:** ကြားရသော detail ၃ ခုရေး/ပြောပါ။
4. Transcript ကြည့်ပြီး shadow ၃ ကြိမ်လုပ်ပါ—listen → pause → copy; နောက်ဆုံးတစ်ကြိမ် transcript မကြည့်ရ။

### C. Controlled Mouth Practice (10 min)

Model Dialogue မှ sentence pattern ၅ ခုရွေးပါ။ လူ၊ နေရာ၊ အချိန် သို့မဟုတ် အမြင်ကို အစားထိုးပြီး pattern တစ်ခုလျှင် sentence ၃ ကြောင်း ခပ်မြန်မြန်ပြောပါ။ မှားလျှင် စာကြောင်းအစမှ အေးအေးဆေးဆေး ပြန်ပြောပါ။

### D. Guided Personal Talk

ဒီ unit topic ကို ကိုယ့်အတွေ့အကြုံနဲ့ချိတ်ပြီး **အချက် ၅ ချက်** ပြောပါ။ `First...`, `One example is...`, `The reason is...`, `Another thing is...`, `So...` frame များသုံးနိုင်သည်။ Partner က `Why?`, `Can you give an example?`, `What happened next?` တို့ထဲက follow-up အနည်းဆုံး ၃ ခုမေးရမည်။

### E. Information Gap / Role-play (12 min)

- **Student A:** ကိုယ့်အတွက် လိုအပ်သော detail ၅ ခုကို လျှို့ဝှက်ရွေးပြီး မပြပါနှင့်။
- **Student B:** မတူသော detail ၅ ခုရွေးပါ။
- Topic နဲ့ဆိုင်တဲ့ plan/decision တစ်ခုကို နှစ်ဦးသဘောတူအောင် မေးခွန်းမေး၊ option နှိုင်းယှဉ်၊ နားလည်မှုစစ်ပါ။ Detail အားလုံးကို ရှာမတွေ့မချင်း task မပြီးပါ။ Role ပြောင်းပြီး ထပ်လုပ်ပါ။

### F. Conversation Repair

- `Could you clarify what you mean?`
- `Let me check that I understood you correctly.`

Phrase နှစ်ခုကို role-play ထဲမှာ တစ်ကြိမ်စီ မဖြစ်မနေသုံးပါ။

### G. Free Talk & Recording

Notes မကြည့်ဘဲ topic အကြောင်း **4–5 မိနစ်** ပြောပြီး ဖုန်းနဲ့ record လုပ်ပါ။ [Speaking Rubric](../Assessments/Speaking-Rubric.md) ထဲက **Fluency, Task Achievement, Interaction** ကို score ပေးပါ။ ကောင်းတာ ၂ ခုနဲ့ ပြင်မည့်အချက် ၁ ခုရေးပြီး ပြန် record လုပ်ပါ။

### H. Recycling

- **3 days:** phrase ၅ ခု + ၁ မိနစ် talk ကို memory မှလုပ်ပါ။
- **7 days:** role-play ကို role အသစ်နဲ့ ပြန်လုပ်ပါ။
- **30 days:** recording ပြန်လုပ်ပြီး rubric score နှိုင်းပါ။
