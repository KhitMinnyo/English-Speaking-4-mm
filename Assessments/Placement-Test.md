# Baseline & Placement Test

## ရည်ရွယ်ချက်

Course မစခင် လက်ရှိ speaking/listening ability ကို baseline ယူရန်ဖြစ်သည်။ ဒါက medical/exam diagnosis မဟုတ်သလို task တစ်ကြိမ်တည်းဖြင့် CEFR certification မပေးပါ။ Phone recording, timer, paper တို့သာလိုသည်။

## Part A — Speaking (20–30 minutes)

Task တစ်ခုစီကို recording ခွဲသိမ်းပါ။ မဖြေနိုင်လျှင် မကျော်မဖြစ်မဟုတ်ပါ။

1. **Personal introduction (1 minute):** name, home, work/family, reason for learning
2. **Daily life (2 minutes):** typical weekday and yesterday
3. **Role-play (3 minutes):** restaurant order မှားနေသည်—ရှင်းပြ၊ ပြင်ခိုင်း၊ follow-up မေး
4. **Story (3 minutes):** အခက်အခဲတစ်ခု၊ ဖြစ်စဉ်၊ ဖြေရှင်းပုံ၊ ရလဒ်
5. **Opinion (4 minutes):** “Adults should continue learning throughout life.” Reasons, example, counterpoint
6. **Advanced response (5 minutes):** Technology makes communication better and worse—qualify claims, respond to one imagined objection, conclude

Task 1–2 မှ စတင်ပြီး learner အလွန်ပင်ပန်း/မလုပ်နိုင်ပါက ရပ်နိုင်သည်။ Task တစ်ခုစီကို `Speaking-Rubric.md` ဖြင့် score ပေးပါ။

## Part B — Listening (teacher/partner script)

ဖတ်ပေးသူက `Placement-Listening-Script.md` ကို learner မမြင်အောင် natural speed ဖြင့် နှစ်ကြိမ်ဖတ်ပါ။ Learner က:

- first listen: main idea တစ်ကြောင်း
- second listen: who/what/when/problem/decision ကို မှတ်
- oral retell: 60–90 seconds
- clarification questions: အနည်းဆုံး ၂ ခု

## Starting recommendation

| Evidence | စတင်ရန် |
|---|---|
| Basic personal answer မတည်ဆောက်နိုင်သေး၊ rubric ပျမ်းမျှ 1–2 | Level 1 |
| Daily/work/travel ကို ဆက်ပြောနိုင်သော်လည်း interaction/tense အားနည်း၊ ပျမ်းမျှ 2–3 | Level 2 |
| Abstract opinion, story, repair လုပ်နိုင်၊ ပျမ်းမျှ 3–4 | Level 3 |
| Unfamiliar complex topic ကို nuance/register ဖြင့်ဆွေးနွေးနိုင်၊ repeated tasks ပျမ်းမျှ 4+ | Level 4 diagnostic path |

သံသယရှိလျှင် အောက် Level ၏ checkpoint မှစပြီး gap ကို ဖြည့်ပါ။ အသက်ကြီးသူများအတွက် speed ကြောင့်သာ level မလျှော့ပါနှင့်—processing time ပေးပြီး language ability ကိုတိုင်းပါ။
