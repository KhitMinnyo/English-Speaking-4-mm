# Unit 08: Mixed Conditionals & Talking About Regret

## Goal

ဒီ unit ပြီးရင် အတိတ်က ဖြစ်ခဲ့တဲ့ အရာအပေါ် regret နဲ့ hypothetical အတိတ်/ပစ္စုပ္ပန်ကို ရောယှက်ပြီး ပြောနိုင်ပါလိမ့်မယ်။

## 1. Vocabulary Warm-up

| English | Burmese | Example |
|---|---|---|
| I should have... | ...သင့်တယ်လေ (လုပ်ခဲ့ရင်ကောင်းမည်) | I should have studied harder. |
| I wish I had... | ...ရင်တော့ ကျေနပ်မယ် | I wish I had taken that job. |
| if only... | ...ရင်တော့လား | If only I had known earlier. |
| in hindsight | နောက်ကြည့်လိုက်ရင်တော့ | In hindsight, it was a mistake. |

## 2. Grammar/Language Point: Third Conditional & Mixed Conditionals

Third Conditional: If + past perfect, would have + V3 — imaginary past. Mixed Conditional: If + past perfect, would + base verb — past condition, present result.

Examples:
- If I had studied harder, I would have passed the exam. (past-past)
- If I had taken that job, I would be rich now. (past condition → present result: mixed)
- I wish I had told her the truth.

## 3. Model Dialogue

A: If I had taken that job in Singapore, I would be in a completely different place now.
B: Do you regret not taking it?
A: Honestly, in hindsight, yes. I wish I had been braver back then.
B: Well, if you had taken it, you might not have met your wife here!
A: True — if only we could see the future when we make decisions.
B: That's life. You can't have it both ways.

## 4. Practice Exercise

Complete with Third/Mixed Conditional:

1. If I ___ harder, I ___ the exam. (study / pass)
2. If she ___ that job, she ___ rich now. (take / be) (mixed)
3. I wish I ___ about this earlier. (know)
4. If we ___ earlier, we ___ the flight. (leave / not miss)
5. In hindsight, I ___ him the truth. (should/tell)

Answer key: 1. had studied, would have passed 2. had taken, would be 3. had known 4. had left, wouldn't have missed 5. should have told

## 5. Speaking Drill

Partner ကို ဘဝထဲက regret တစ်ခု (small or big) share လုပ်ပြီး "If I had..., I would have/would be..." structure နဲ့ ပြန်ပြောကြည့်ပါ။

## 6. Pronunciation Focus

"would have" ကို connected speech မှာ "would've" /wʊdəv/ (sometimes sounds like "woulda") — listening အတွက် မှတ်ထားပါ။

## 7. Can-do Checklist

- [ ] I can talk about past regrets using third conditional
- [ ] I can use mixed conditionals to connect past causes with present results
- [ ] I can express hindsight naturally using "in hindsight" and "I wish I had..."

## Speaking-First Extension (မဖြစ်မနေ လုပ်ရန်)

> **Topic:** Unit 08: Mixed Conditionals & Talking About Regret  
> **စုစုပေါင်း ပါးစပ်ဖြင့်ပြောချိန်:** 60–100 မိနစ် (တစ်ခါတည်းမလို—အပိုင်းခွဲနိုင်သည်)

### A. Quick Retrieval (3–5 min)

စာအုပ်ကိုပိတ်ပြီး ဒီ unit မှ အသုံးဝင်သော phrase ၅ ခုကို အသံထွက်ပြောပါ။ Phrase တစ်ခုစီနဲ့ ကိုယ့်ဘဝအကြောင်း sentence အသစ်တစ်ကြောင်း ဆောက်ပါ။ မမှတ်မိလျှင် ကြည့်ပြီး ပြန်ပိတ်ကာ ထပ်ပြောပါ။

### B. Listening Lab

[`Unit-08-Mixed-Conditionals-Regret Listening Lab`](../Audio-Scripts/Level-3-Advanced/Unit-08-Mixed-Conditionals-Regret-Listening.md) ကို အသုံးပြုပါ။

1. **မနားထောင်မီ:** ဘယ်သူတွေ၊ ဘယ်နေရာ၊ ဘာပြဿနာဖြစ်နိုင်သလဲ ခန့်မှန်းပါ။
2. **Slow version:** အဓိကအကြောင်းကို sentence တစ်ကြောင်းနဲ့ ပြောပါ။
3. **Natural version:** ကြားရသော detail ၃ ခုရေး/ပြောပါ။
4. Transcript ကြည့်ပြီး shadow ၃ ကြိမ်လုပ်ပါ—listen → pause → copy; နောက်ဆုံးတစ်ကြိမ် transcript မကြည့်ရ။

### C. Controlled Mouth Practice (15 min)

Model Dialogue မှ sentence pattern ၅ ခုရွေးပါ။ လူ၊ နေရာ၊ အချိန် သို့မဟုတ် အမြင်ကို အစားထိုးပြီး pattern တစ်ခုလျှင် sentence ၃ ကြောင်း ခပ်မြန်မြန်ပြောပါ။ မှားလျှင် စာကြောင်းအစမှ အေးအေးဆေးဆေး ပြန်ပြောပါ။

### D. Guided Personal Talk

ဒီ unit topic ကို ကိုယ့်အတွေ့အကြုံနဲ့ချိတ်ပြီး **အချက် ၅ ချက်** ပြောပါ။ `First...`, `One example is...`, `The reason is...`, `Another thing is...`, `So...` frame များသုံးနိုင်သည်။ Partner က `Why?`, `Can you give an example?`, `What happened next?` တို့ထဲက follow-up အနည်းဆုံး ၃ ခုမေးရမည်။

### E. Information Gap / Role-play (15–20 min)

- **Student A:** ကိုယ့်အတွက် လိုအပ်သော detail ၅ ခုကို လျှို့ဝှက်ရွေးပြီး မပြပါနှင့်။
- **Student B:** မတူသော detail ၅ ခုရွေးပါ။
- Topic နဲ့ဆိုင်တဲ့ plan/decision တစ်ခုကို နှစ်ဦးသဘောတူအောင် မေးခွန်းမေး၊ option နှိုင်းယှဉ်၊ နားလည်မှုစစ်ပါ။ Detail အားလုံးကို ရှာမတွေ့မချင်း task မပြီးပါ။ Role ပြောင်းပြီး ထပ်လုပ်ပါ။

### F. Conversation Repair

- `Let me rephrase that more precisely.`
- `If I understand your point correctly, ...`

Phrase နှစ်ခုကို role-play ထဲမှာ တစ်ကြိမ်စီ မဖြစ်မနေသုံးပါ။

### G. Free Talk & Recording

Notes မကြည့်ဘဲ topic အကြောင်း **6–8 မိနစ်** ပြောပြီး ဖုန်းနဲ့ record လုပ်ပါ။ [Speaking Rubric](../Assessments/Speaking-Rubric.md) ထဲက **Fluency, Task Achievement, Interaction** ကို score ပေးပါ။ ကောင်းတာ ၂ ခုနဲ့ ပြင်မည့်အချက် ၁ ခုရေးပြီး ပြန် record လုပ်ပါ။

### H. Recycling
